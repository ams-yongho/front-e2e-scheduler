# 대시보드 프로젝트 그리드 상세 전환 설계

## 목표

대시보드 메인 화면에서 모든 프로젝트의 상세 실패 내용을 한 번에 길게 나열하지 않는다. 메인은 프로젝트별 핵심 상태를 2열 그리드로 빠르게 스캔할 수 있게 만들고, 사용자가 프로젝트를 선택하면 해당 프로젝트의 상세 결과 화면으로 전환한다.

## 사용자 흐름

1. 사용자는 대시보드에 진입해 상단 전체 요약과 2열 프로젝트 그리드를 본다.
2. 각 프로젝트 타일에는 최신 실행 결과의 핵심 정보만 표시된다.
3. 사용자가 프로젝트 타일을 선택하면 선택한 프로젝트의 상세 화면으로 전환된다.
4. 상세 화면에는 기존 `ProjectCard`가 제공하던 통과율, 브라우저별 결과, 실패 상세, flaky 테스트, 느린 테스트, 30일 히스토리를 표시한다.
5. 상세 화면의 `프로젝트 목록` 액션 또는 브라우저 뒤로가기로 메인 그리드로 돌아간다.

## 메인 화면

메인 레이아웃은 현재 헤더와 전체 SummaryBar를 유지하고, 본문을 `ProjectCard` 목록 대신 `ProjectGrid`로 교체한다.

프로젝트 타일은 데스크톱에서 2열로 배치한다. 모바일 또는 좁은 화면에서는 1열로 전환한다. 타일은 카드 안에 아래 정보를 포함한다.

- 프로젝트명
- 상태 배지: `통과`, `실패`, `데이터 없음`
- 통과율과 `passed/total`
- 실행 시간
- 실패 수
- flaky 수
- 최신 실행일
- 최근 통과율 추이 sparkline

실패 프로젝트는 왼쪽 강조선과 배경 tint를 `danger` 계열로 표시한다. 통과 프로젝트는 `success`, 데이터가 없는 프로젝트는 muted 계열을 사용한다. 타일 전체는 클릭 가능한 버튼 또는 링크 역할을 하며 키보드 포커스가 가능해야 한다.

## 상세 화면

상세 화면은 선택된 프로젝트 하나만 렌더링한다. 기존 `ProjectCard` 컴포넌트를 상세 화면의 본문으로 재사용해 현재의 긴 실패 상세 UI를 유지한다.

상세 화면 상단에는 `프로젝트 목록`으로 돌아가는 액션을 둔다. 선택된 프로젝트가 없거나 URL에 존재하지 않는 프로젝트명이 들어오면 메인 그리드로 돌아가거나 `등록된 결과가 없습니다` 상태를 보여준다.

## URL 상태

새 라우터를 도입하지 않고 `URLSearchParams` 기반 쿼리 상태를 사용한다.

- 메인: `/`
- 상세: `/?project=biz-admin`

타일 선택 시 `history.pushState`로 `project` 쿼리를 설정한다. 브라우저 뒤로가기와 앞으로가기를 지원하기 위해 `popstate` 이벤트에서 선택 상태를 갱신한다.

이 방식은 의존성을 추가하지 않고도 상세 링크 공유와 브라우저 내비게이션을 지원한다.

## 컴포넌트 구조

- `App.tsx`: URL 쿼리 상태를 읽고 메인/상세 화면을 분기한다.
- `ProjectGrid.tsx`: 프로젝트 타일 목록과 빈 상태를 렌더링한다.
- `ProjectTile.tsx`: 최신 결과 요약, 상태 색상, sparkline을 표시한다.
- `ProjectCard.tsx`: 상세 화면에서 기존 상세 UI로 재사용한다.

`ProjectData` 타입은 `App.tsx`에서 export해 `ProjectGrid`와 `ProjectTile`이 동일한 타입을 사용한다. 별도 파일을 만들지 않아 이번 변경 범위를 작게 유지한다.

## 에러와 빈 상태

결과 로딩 실패는 기존 에러 메시지를 유지한다. 프로젝트가 없으면 현재의 `등록된 프로젝트가 없습니다` 문구를 메인 영역에 표시한다.

프로젝트는 있지만 특정 프로젝트의 최신 결과가 없으면 타일에 `데이터 없음` 상태를 표시하고, 상세 화면에서는 프로젝트명과 함께 결과가 아직 없다는 안내를 보여준다.

## 테스트 전략

기존 `ProjectCard` 테스트는 유지한다. 새 UI에 대해서는 아래를 검증한다.

- `ProjectGrid`가 프로젝트 타일을 렌더링한다.
- 실패/통과/데이터 없음 상태별 배지가 표시된다.
- 타일 클릭 시 `project` 쿼리로 이동 요청이 발생한다.
- `App`이 `?project=...` URL에서 해당 프로젝트 상세만 렌더링한다.
- 상세 화면의 목록 버튼이 메인 그리드로 돌아간다.

최종 검증은 `pnpm test`, `pnpm build`로 수행한다. UI 변경 후 로컬 브라우저에서 메인 그리드와 상세 전환을 확인한다.
